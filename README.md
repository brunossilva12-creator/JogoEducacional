<a name="português"></a>
## 🇧🇷 Português

Um jogo educacional interativo sobre cartografia e geografia desenvolvido com o auxílio de Inteligência Artificial durante o curso de Desenvolvimento de Sistemas. O jogador assume o papel de um explorador em uma jornada por diferentes níveis de conhecimento para conquistar os mares da Geografia.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/JogoEducacional](https://brunossilva12-creator.github.io/JogoEducacional/)

### ✨ Funcionalidades
- **Sistema de Níveis Progressivos:** Desafios divididos em *Nível Básico* (conceitos fundamentais), *Nível Intermediário* (distâncias reais) e *Nível Avançado* (análise de mapas e escalas), desbloqueados conforme o avanço do jogador.
- **Missão Especial:** Um modo extra com seis desafios misturados para testar a capacidade geral de exploração.
- **Sala das Conquistas e Ranking Local:** Sistema de selos, troféus e placar dos dez maiores exploradores, com progresso salvo automaticamente no navegador (`LocalStorage`).
- **Desenvolvimento Assistido por IA:** Projeto idealizado e construído utilizando ferramentas de Inteligência Artificial como apoio na criação da estrutura, lógica e conteúdo educacional.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica das telas do jogo (menu, diário de bordo, desafios e ranking).
- **CSS3:** Estilização temática de navegação, barras de progresso e layout responsivo.
- **JavaScript:** Lógica do quiz, controle de pontuação, desbloqueio de níveis e persistência de dados no navegador.
- **Inteligência Artificial:** Apoio na geração de código, mecânicas de gamificação e questões geográficas.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/brunossilva12-creator/JogoEducacional/tree/main
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

<a name="english"></a>
## 🇺🇸 English

An interactive educational game about cartography and geography developed with the assistance of Artificial Intelligence during the Systems Development course. Players take on the role of an explorer on a journey through different knowledge levels to conquer the seas of Geography.

🔗 **Live Demo:** [brunossilva12-creator.github.io/JogoEducacional](https://brunossilva12-creator.github.io/JogoEducacional/)

### ✨ Features
- **Progressive Level System:** Challenges divided into *Basic Level* (fundamental concepts), *Intermediate Level* (real distances), and *Advanced Level* (map and scale analysis), unlocked as the player progresses.
- **Special Mission:** A bonus mode featuring six mixed challenges to test overall exploration skills.
- **Hall of Achievements & Local Leaderboard:** Badges, trophies, and a top-ten explorers ranking with progress automatically saved in the browser (`LocalStorage`).
- **AI-Assisted Development:** Project designed and built using Artificial Intelligence tools to support structure, game logic, and educational content creation.

### 🛠️ Technologies Used
- **HTML5:** Semantic structure of game screens (menu, logbook, challenges, and leaderboard).
- **CSS3:** Nautical-themed styling, progress bars, and responsive layout.
- **JavaScript:** Quiz logic, scoring system, level unlocking, and browser data persistence.
- **Artificial Intelligence:** Support in code generation, gamification mechanics, and geography questions.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/brunossilva12-creator/JogoEducacional/tree/main
   ```
2. Open the project folder and launch the `index.html` file in your browser.
